## ⚠️ ВЫЯВЛЕННЫЕ ПРОБЛЕМЫ

### 1. Фрагментация Track ID 🔀

**Проблема:** 22 track ID для 2 жокеев (ожидалось ~3)

**Разбивка:**
- Желтый жокей: 11 track IDs → должен быть 1
- Зеленый жокей: 11 track IDs → должен быть 1

**Причина:** Трекер (nvtracker) теряет объекты и создает новые ID при повторном появлении

**Решение:**
- Увеличить IOU threshold в конфиге трекера
- Рассмотреть переход на DeepSORT вместо IOU tracker
- Добавить логику слияния track ID на основе цвета + временной близости
